今後開発で依存関係を追加したときにも、環境を再現しやすくするために、仮想環境を構築する手順を以下に示します。
requirements.txtは、プロジェクトルートに置いています。

conda create -n 環境名 python=3.11 --no-default-packages #<<最初だけ
conda activate 環境名
python -m pip install -U pip setuptools wheel
pip install -r requirements.txtへのパス

flask run --host=0.0.0.0 --port=5000
↑このコマンドで起動
----
 * Running on all addresses (0.0.0.0)
 * Running on http://127.0.0.1:5000
 * Running on http://10.141.114.66:5000＜＜＜＜これを使用
 ----
 三行目のリンクをアンドロイドアプリ側、local.propertiesの
 SERVER_URL=http://192.168.0.0.1000
 を修正する
